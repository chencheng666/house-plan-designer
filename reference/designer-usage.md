# 设计器操作与交付说明

- 打开后的用法：左侧“户型”面板可以勾选“显示底图”对照原图；“载入初始户型”随时恢复到这个户型；其余功能（3D 漫游、家具、水电、吊顶、拆改、报价、导出 PDF/分享文件）和原设计器一样；「导出图纸 → CAD 平面布置图（DXF · 国标 / 装修）/ CAD 水电点位图（DXF）」导出 DXF R2007（文字 UTF-8，中文不乱码；模型空间 1:1 mm），按 GB/T 50001 / 50104 出图习惯：分图层并设线宽（墙柱粗线 0.5、门窗 0.25、家具尺寸 0.13）、承重墙涂黑、新砌墙 45° 斜线图例、拆除墙虚线、门开启线细实线、定位轴线 + 轴号（1、2、3… / A、B、C…，不用 I O Z）、尺寸两种导出：国标三道（门窗洞口 / 轴线 / 总尺寸）或装修四道（多一道墙厚 + 净距），间距 10mm、第一道离外轮廓 10mm，短段数字错开 + 引出线；每段尺寸都是真正的 DIMENSION 标注对象（标注样式 GB：45° 建筑斜线、字高 3、DIMSCALE = 比例，数字由 CAD 按定义点量，和图形一致）；门窗编号（M / TLM / DK / C / GC / TC + 宽高分米，撞号加 a、b）+ 门窗表（毫米实数、数量、窗台高、入户门）、指北针、图名 + 比例、A3/A2 图框 + 标题栏，比例自动选（优先 1:100），可再用 cadvec.py 读回来；选中橱柜、定制柜、浴室柜、淋浴房、中岛，属性面板有「定制」区：橱柜可改一字 / L / U 形、进深、台面高厚和颜色、水槽灶台在哪一段和位置宽度、吊柜、烟机、高柜，定制柜可改每列宽和类型、L 形转角、顶柜、踢脚、拉手、顶天立地，2D / 3D / 立面 / 报价 / 水电同步（冰箱洗衣机等成品家电保持标准尺寸）；3D 里点墙上的开关能开关对应的灯（夜间模式最明显），门、窗帘、电视、台灯也能点；水电面板有“一键布置水电”和「管线排布」（全部 / 电路 / 网线 / 给排水切换，插座回路走地或走顶、给水走顶或走地，回路表、材料清单 CSV，点中一段管线拖动改走向、恢复自动走线，选中插座改所属回路；DXF 水电图按系统分图层带管线）；3D「⚡ 管线」把管线按真实高度放进模型、墙半透明；写实风格漫游：GTAO 接触阴影、窗户面光源（窗帘拉上会暗）、家具小倒角、布艺 / 木纹 / 乳胶漆微纹理、窗外城市远景（夜里亮窗）、室内摄影调色，顶面不再漏光；「风格」里有画质档位（流畅 / 均衡 / 高画质，默认按显卡自动选；均衡以上有布艺丝绒光泽、烤漆清漆、木纹布纹凹凸、房间反弹光、抗锯齿）；软装是鼓包的填充感垫子、带包边，被子有褶皱；☀ 面板「出图方式」可选光线追踪（three-gpu-pathtracer，首次编译核显约 1~2 分钟，有进度条、可提前结束保存，最后降噪）；3D 视图「🎨 风格」可切换写实 / 沙盘效果图（微缩模型感）/ 彩平图（正上方俯视的彩色平面图，标准门窗符号、房间名和面积、指北针、比例尺；尺寸可选不标 / 简洁 / 完整，彩平图模式下「渲染出图」直接出完整彩平图）和 12 套配色，鸟瞰、漫游、出图都保持；「导出图纸 → 彩平图（高清 PNG）」直接出一张长边 4000 像素的彩平图；房间面板里可以「自定义铺砖」（砖的长宽、灰缝、8 种铺法、纹理、砖色缝色、起铺点），2D / 3D / 报价同步，报价按整砖 + 切砖片数算；右侧总览里可以开关三类尺寸标注（外墙门窗分段、每段墙净长、房间开间 × 进深），改墙后实时重算，导出图纸也带上；☀ 面板按城市、月份、时间模拟真实日照，夜里出月亮星空，有“日照演示”；🔒 锁定后 3D 里不能拖动家具（防误触）；3D 里的动效都是平滑的：门、窗（平开窗往里转开、推拉窗滑开，3D 里点窗扇就能开关）、窗帘（一褶一褶收拢展开，可停在任意开合度）、开关灯淡入淡出、电视屏亮起、楼层切换时楼层滑开 / 滑回；3D 视图「🏠 智能中控」（参考 HAbridge 智能家居仪表盘的演示，单层套房和多层都能用）：把方案当成装好智能家居的房子来用——墙面变成白色半透明、能看到房间里面，开着的灯在地面打出暖色光池、灯具周围有光晕（色温、亮度一调就看得出）；左侧问候、日期农历、当地日出日落、灯光 / 空调 / 窗帘开着几台和室内 PM2.5 / 温度 / 湿度曲线（模拟数据），右侧楼层（多层时 ALL = 各层拉开的爆炸视图、缓慢自转），底部灯光 / 环境 / 设备 / 扫地机 / 安防五类，3D 里设备上浮出图标，点图标镜头推到房间、弹出控制卡片：灯（色温 2700~6500K、亮度、柔和 / 日常 / 明亮）、窗帘（开合百分比、关闭 / 暂停 / 打开）、空调（温度、模式、风速、摆风，3D 里出风气流：制冷蓝、制热橙）、电视等设备开关、扫地机器人（每层一台、在自己那层跑；100mm 栅格避障规划：墙、落地家具、楼梯、楼梯井绕开不穿模，桌椅底下能钻，关着的门进不去，路被挡住会重新找路或跳过；能到达的地面弓字形覆盖，地上留青色清扫轨迹；电量低自动走最短路回基站充电、充满接着扫；卡片显示进度、已扫面积、电量、跳过的区域；方案里没放基站时在客厅连通面积最大的那片地面靠北墙处放一个虚拟基站）、门窗（开关、入户门上锁、一键关闭全部门窗）；切换楼层时别的层边滑开边淡出；挑高（层高 > 3.1m）的一层在 2.8m 处剖开，也看得清每个房间；状态只在本次打开有效、不存进方案。想让中控演示更完整，布置家具时记得放上空调、窗帘、电视、灯具（autoElec 会布灯）
